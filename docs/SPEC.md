# 参赛题目

本赛题要求参赛者从图片或 `PDF` 文件中识别复杂表格，并根据题目要求完成表格结构恢复、表格内容提取或表格内容推理计算。参赛者需要读取比赛提供的题目清单 `Excel` 文件，针对每一道题生成答案，并提交一份结果 `Excel`
文件。

表格文件可能来自财务报表、销售报表、采购对账单、质检报告、物流结算单、统计报表等真实业务文档。文件中可能包含复杂版式、跨页表格、合并单元格、多级表头、弱边框、页眉页脚干扰、脚注混入、旋转扫描、单位变化和字段继承
等情况。

参赛者的目标不是只识别页面中是否存在表格，而是要理解表格的结构和内容，并根据题目给出可自动评分的最终答案。

题目分为三类：

|     题型     | `question_type` |                           任务说明                           |
| :----------: | :-------------: | :----------------------------------------------------------: |
| 表格结构恢复 |   `structure`   |      还原表格行列结构、单元格文本、单元格位置和合并关系      |
| 表格内容提取 |    `extract`    |           从目标表格中抽取指定单元格、行、列或区域           |
| 表格内容推理 |   `thinking`    | 先定位相关数据，再完成加总、求差、比例、筛选或排序等简单处理 |

### 表格结构恢复

结构恢复题要求参赛者还原指定表格的逻辑结构，包括表格行数、列数、单元格文本、单元格所在行列位置，以及横向或纵向合并关系。

结构恢复题可能要求恢复整张表，也可能只要求恢复局部结构。局部结构题会在题目文本或 `answer_format` 中说明范围，例如“只恢复前 1 行和前 1 列”。局部结构题仍然使用结构恢复题的同一套 `JSON` 答案格式。

示例题目：

```text
请恢复 file_001.pdf 中第 3 页到第 4 页的销售明细表结构。
```

局部结构恢复示例题目：

```text
请恢复 file_001.pdf 中销售明细表的前 1 行和前 1 列结构。
```

### 表格内容提取

内容提取题要求参赛者从目标表格中抽取指定内容。答案可能是一个单元格、一行、一列或一个区域。

这类题可能要求参赛者根据行标题、列标题、多级表头、单位说明或字段继承关系来定位答案。

示例题目：

```text
请提取 2025 年各个月的销售总额。
```

### 表格内容推理

表格内容推理题要求参赛者先从表格中找到相关数据，再进行简单计算或处理，并输出最终结果。

可能涉及的处理包括：

- 加总
- 求差
- 计算比例或增长率
- 按条件筛选
- 排序后取最大值或最小值
- 对金额、数量、百分比或日期进行格式归一

示例题目：

```text
请计算 2025 年实体商品销售额合计和虚拟商品销售额合计。
```

# 比赛数据

比赛数据包含两部分：

- 表格文件：图片文件或 `PDF` 文件，存放在 `files` 目录下。
- 题目清单：一个 `Excel` 文件，通常命名为 `tests.xlsx`。

`tests.xlsx` 中每一行对应一道题。参赛者需要根据该行中的文件名、题型和题目文本，到对应的图片或 `PDF` 文件中查找答案。

## 题目清单字段如下：

|     字段名      | 是否必填 |                            说明                            |
| :-------------: | :------: | :--------------------------------------------------------: |
|      `id`       |    是    |                        题目唯一编号                        |
|   `file_name`   |    是    |    对应的图片或 `PDF` 文件名，文件保存在 `files` 目录下    |
| `question_type` |    是    |                            题型                            |
|   `question`    |    是    |                          具体题目                          |
|  `table_hint`   |    否    | 如果页面或图片中有多个表格，会有表格提示，例如“销售明细表” |
| `answer_format` |    否    |                    对答案格式的补充说明                    |

### `question_type` 共有三种取值：

|    取值     |     含义     |
| :---------: | :----------: |
| `structure` | 表格结构恢复 |
|  `extract`  | 表格内容提取 |
| `thinking`  | 表格内容推理 |

# 提交结果

参赛者需要提交一个 `Excel` 文件（`.xlsx`），通常命名为 `submission.xlsx`。
提交文件至少包含以下两列：

|  字段名  | 是否必填 |               说明               |
| :------: | :------: | :------------------------------: |
|   `id`   |    是    | 题目唯一编号，必须与题目清单一致 |
| `answer` |    是    |             最终答案             |

每道题只提交一行。不得删除题目，不得重复提交同一个 `id`。如果某道题无法
作答，`answer` 填写空字符串。

所有题型的答案都填写在 `answer` 列中。不同题型的填写方式如下。

## 结构恢复题答案格式

结构恢复题的 `answer` 必须填写一个合法的 `JSON` 字符串。该 `JSON` 必须包含 `row_count`、`col_count` 和 `cells`。

每个真实单元格只输出一次。横向合并用 `colspan` 表示，纵向合并用`rowspan` 表示。被合并覆盖的位置不需要额外输出空单元格或占位单元格。

如果题目只要求局部结构恢复，例如只恢复前 1 行和前 1 列，答案仍使用同一个 `JSON` 结构。`row_count` 和 `col_count` 填写完整表格的逻辑行数和逻辑列数，`cells` 只输出题目要求范围内的真实单元格。`row` 和 `col` 仍按完整表格从 `0` 开始编号，`rowspan` 和 `colspan` 仍表示该单元格在完整表格中的真实合并范围。

字段说明如下：

|   字段名    | 是否必填 |              说明               |
| :---------: | :------: | :-----------------------------: |
| `row_count` |    是    |          表格逻辑行数           |
| `col_count` |    是    |          表格逻辑列数           |
|   `cells`   |    是    |           单元格列表            |
|   `text`    |    是    |           单元格文本            |
|    `row`    |    是    | 单元格左上角所在行，从 `0` 开始 |
|    `col`    |    是    | 单元格左上角所在列，从 `0` 开始 |
|  `rowspan`  |    是    |      单元格纵向占用的行数       |
|  `colspan`  |    是    |      单元格横向占用的列数       |

### 4.2 内容提取题和内容推理题答案格式

如果答案是一个单元格或一个数值，直接填写最终值。

示例：

```text
138000
```

如果答案是一行、一列或一个区域，填写 `JSON` 数组。数组元素使用简单的
键值对象。

示例：

```json
[
  {"月份": "1月", "销售总额": "12000"},
  {"月份": "2月", "销售总额": "13500"},
  {"月份": "3月", "销售总额": "14200"}
]
```

# 答案规范

提交答案时需要遵守以下规则：

- `id` 必须与题目清单完全一致。
- 结构恢复题的 `answer` 必须是合法 `JSON`。
- 结构恢复题中，行列编号从 `0` 开始。
- 局部结构恢复题中，`row_count` 和 `col_count` 仍填写完整表格的逻辑行列数。
- 局部结构恢复题只输出题目要求范围内的单元格，不需要补全未要求的行列。
- 合并单元格只输出左上角单元格，不输出被合并覆盖的位置。
- 文本答案保留原始含义，可以去除多余空格和换行。
- 数字答案去除千分位逗号，例如填写 `125000`，不要填写 `125,000`。
- 日期、金额、百分比和单位按照题目要求填写。
- 如果要求一个数组作为答案，其中某些值在表格中为空，该值填写空字符串。
- 如果题目要求多个结果，使用 `JSON` 数组。
- 不要在答案中写“根据表格可知”“答案是”等说明性文字。

# 评价指标

本赛题采用自动评分。

通过比较参赛者提交的结果与正确答案的比值作为最终的得分，保留一位小数。

计算方法为：`最终得分 = 正确题数 / 总题数 × 100`

得分范围为： `[0 - 100]`
